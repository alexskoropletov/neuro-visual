# Архитектура

videomake собирает видео из текста на своей машине. Облако не участвует в генерации.

```text
TextOrScript
    → LocalLLM (Ollama)
    → ScenePrompts
    → ComfyUI + Wan 2.2 TI2V-5B
    → SceneClips
    → ffmpeg
    → FinalMP4
```

## Роли

**Локальный LLM (Ollama).** Берёт длинный текст или сценарий и режет его на 4–8 сцен. На выходе JSON: visual prompt под Wan, длительность, общие черты персонажей. Модель без встроенного отказа (например `dolphin-llama3`). LLM не рисует кадры.

**Wan 2.2 в ComfyUI.** Единственный генератор картинки/движения в v1. Дефолт — гибрид [Wan2.2-TI2V-5B](https://huggingface.co/Wan-AI/Wan2.2-TI2V-5B): один чекпоинт для text-to-video и позже image-to-video. Safety-checker в native-пайплайне ComfyUI не подключается. Partner/API-ноды не используются.

**ffmpeg.** Склеивает клипы сцен в один mp4. Не генерирует контент.

**Локальный UI (`ui/server.py`).** Браузерная оболочка на стандартной библиотеке Python. Режет сценарий через Ollama, ставит сцены в очередь ComfyUI (`/prompt`) и вызывает `scripts/stitch.sh`. Слушает только `127.0.0.1`.

ComfyUI остаётся движком генерации. Репозиторий — инструкция, workflow, скрипты и UI.

## Почему гибрид

Wan выдаёт короткие клипы (секунды, не минуты). Длинный сюжет не влезает в один промпт без потери структуры. LLM держит нарратив и единообразие персонажей, Wan — визуал каждой сцены, ffmpeg — таймлайн.

## Данные на диске

- `output/scenes.json` — список сцен после нарезки
- `output/scenes/` — клипы (`scene-01.webm`, …)
- `output/final.mp4` — склейка

Веса моделей лежат в каталогах ComfyUI, не в этом репозитории.
